# Матрица edge cases

| Ситуация | Что обнаруживаем | Решение | Автоответ допустим? | Почему | Статус |
|---|---|---|---|---|---|
| Обычный поддерживаемый FAQ | Уверенная тема и релевантная статья KB | `draft_ready` с evidence | Да, для безопасного черновика | Ответ строится на найденном основании | IMPLEMENTED IN POC |
| Жёсткий риск / компрометация аккаунта | Маркеры взлома или несанкционированного доступа | Немедленно `needs_review` оператору | Нет | Генерация не вызывается | IMPLEMENTED IN POC |
| Оспариваемая финансовая операция | Маркеры подозрительной операции или несанкционированного списания | Немедленно `needs_review` оператору | Нет | Высокая цена false negative | IMPLEMENTED IN POC |
| Чувствительные учётные данные | Просьба передать SMS-код или пароль | Немедленно `needs_review` оператору | Нет | Секрет нельзя раскрывать или подтверждать автоматически | IMPLEMENTED IN POC |
| Обезличиваемая PII: email или телефон | Известный шаблон PII | Обезличить и продолжить обработку | Да, если остальные проверки пройдены | В PoC показана только малая часть шаблонов PII | IMPLEMENTED IN POC |
| Неизвестная или low-confidence тема | Нет темы либо score ниже демонстрационной границы | `needs_review` оператору | Нет | При неопределённости PoC fail-closed | IMPLEMENTED IN POC |
| Конфликтующая или неоднозначная тема | Равные scores нескольких тем | `needs_review` оператору | Нет | Нельзя выбирать маршрут по произвольному tie-break | IMPLEMENTED IN POC |
| Нет релевантного evidence в KB | Retrieval ниже минимальной границы | `needs_review` оператору | Нет | Нельзя придумывать ответ без основания | IMPLEMENTED IN POC |
| Генератор недоступен или timeout | Ошибка внешнего генератора | В PoC — `needs_review`; в target — bounded retry/fallback | Нет в PoC | Отказ зависимости не должен открывать автоматический ответ | PoC: IMPLEMENTED; timeout: TARGET-DESIGN ONLY |
| Unsafe или ungrounded draft | Не пройдена deterministic grounding/safety gate | `needs_review` оператору | Нет | Черновик без достаточного основания блокируется | PoC gate: IMPLEMENTED; semantic safety: TARGET-DESIGN ONLY |
| Prompt-like инструкции в тикете или retrieved-тексте | Текст пытается изменить правила обработки | Считать текст данными; при конфликте — review | Нет для произвольных действий | В PoC нет tools/actions; layered mitigation не является гарантией | TARGET-DESIGN ONLY |
| Пустой или некорректный вход | Пустая строка/пробелы или нарушение контракта `Ticket` | Пустой текст — `needs_review`; некорректная структура отклоняется вызывающим слоем | Нет | Невалидный вход не должен запускать генерацию | Пустой текст: IMPLEMENTED; validation слоя: TARGET-DESIGN ONLY |
| Ошибка записи аудита | Не удалось сохранить обязательное событие | Fail-closed: исключение не даёт вернуть `draft_ready` | Нет | Автоматическое решение без аудита не считается успешным | IMPLEMENTED IN POC |
| Повторная доставка или retry | Один `operation_id` приходит повторно | В target — атомарный claim и тот же idempotency key | Не определено в PoC | Дублирующие side effects исключаются на уровне durable state | TARGET-DESIGN ONLY |
