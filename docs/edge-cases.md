# Матрица пограничных случаев

| Ситуация | Решение | Автоответ допустим? | Основание | Статус |
|---|---|---|---|---|
| Типовой вопрос из поддерживаемой базы знаний | `draft_ready` с идентификатором статьи | Да, только для безопасного черновика | Есть уверенная тема и найденное основание | Реализовано и проверено |
| Компрометация аккаунта | `needs_review` оператору | Нет | Генератор и поиск не вызываются | Реализовано и проверено |
| Спорная финансовая операция | `needs_review` оператору | Нет | Цена пропуска риска высока | Реализовано и проверено |
| Просьба передать код из SMS или пароль | `needs_review` оператору | Нет | Секрет нельзя подтверждать или запрашивать автоматически | Реализовано и проверено |
| Адрес электронной почты или телефон | Скрыть значение и продолжить обработку | Да, если остальные проверки пройдены | PoC распознаёт только эти два шаблона PII | Реализовано и проверено |
| Неизвестная либо неоднозначная тема | `needs_review` оператору | Нет | При недостаточной уверенности PoC безопасно отказывается от автоответа | Реализовано и проверено |
| Нет подходящей статьи | `needs_review` оператору | Нет | Нельзя формировать ответ без основания | Реализовано и проверено |
| Ошибка или тайм-аут OpenRouter | `needs_review` без черновика | Нет | Внешняя ошибка не должна открывать автоответ | Реализовано и проверено с подставным HTTP-клиентом; живой вызов не проводился |
| Черновик не проходит проверку | `needs_review` оператору | Нет | Детерминированный черновик проверяется по статье; семантическая оценка LLM ещё не реализована | Проверка PoC реализована и проверена; семантическая оценка — целевая система |
| Инструкция в тикете или найденном тексте пытается изменить правила | Передать текст как данные; при конфликте — оператор | Нет для произвольных действий | Сообщения разделяют системную политику, данные тикета и утверждённый источник; у LLM нет инструментов | Граница реализована и проверена; устойчивость конкретной модели требует отдельной оценки |
| Пустой или неверный вход | Пустой текст — `needs_review`; неверный HTTP-запрос — `422` | Нет | Некорректные данные не доходят до генератора | Реализовано и проверено |
| Не удалось записать аудит | Не возвращать успешный `draft_ready` | Нет | Автоматическое решение без аудита не считается завершённым | Реализовано и проверено |
| Повторная доставка задания | Атомарный захват по `operation_id` | Не определено в PoC | Исключение повторного внешнего действия требует постоянного состояния | Только целевая система |
